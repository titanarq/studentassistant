# Student Assistant

Turn handwritten class notes into faithful digital study notes by **showing them to your phone
and talking about them**. An Ubuntu PC transcribes your voice locally, keeps every source, lets
Claude Sonnet follow the session live and Claude Opus build the master notes with you; quizzes,
flashcards, exams and slides come from those notes. Everything you produce lives in your own
private GitHub repository (the *vault*), so any PC can pick up where you left off.
